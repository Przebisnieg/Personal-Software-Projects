## Projects

### 1. Ticket Price Calculator

A web-based calculator developed to simplify the calculation of individual railway ticket prices when multiple tickets with different discounts are purchased together.

The application reconstructs the original base fare and individual discounted prices from the total transaction amount, helping railway staff perform calculations during ticket inspections.

**Key features:**
- Reverse calculation of the original base fare
- Support for multiple tickets and individual discounts
- Automatic price recalculation
- Dynamic addition and removal of tickets
- Individual ticket price breakdown

**Technologies:** HTML5, CSS3, JavaScript
